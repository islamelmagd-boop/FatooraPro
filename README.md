# فاتورة برو - FatooraPro v2.0
منظومة إدارة الفواتير والمبيعات السحابية والتجارية مع دعم نقاط البيع (POS) وتكامل أندرويد وويب.

## مكونات المشروع
1. **web/**: واجهة الويب التفاعلية (HTML5 / CSS3 / JavaScript PWA)
2. **server/**: خادم واجهات البرمجة Node.js & Express
3. **android/**: تطبيق أندرويد WebView هجين لربط المنظومة بالأجهزة اللوحية وطابعات الفواتير الحرارية
